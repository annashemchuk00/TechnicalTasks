\# 🏢 Conference Room Booking API

Навчальний проект REST API для управління конференц-залами, їх бронювання та автоматичного розрахунку вартості оренди.



\---



\## 📝 Про проект



Сервіс розроблений для автоматизації процесів оренди залів. API дозволяє додавати нові приміщення, шукати вільні затишні місця під потрібний час і місткість, додавати додаткові послуги та автоматично рахувати підсумкову вартість із урахуванням часових тарифів.



\---



\## ⚙️ Основні можливості



\### 1. Управління залами (Conference Rooms)

\* \*\*Створення залу\*\* — додавання назви, місткості, базової ціни та списку послуг.

\* \*\*Редагування\*\* — оновлення інформації про зал чи його ціну.

\* \*\*Видалення\*\* — вилучення залу за його `ID`.

\* \*\*Пошук\*\* — фільтрація вільних залів за датою, часом та місткістю.



\### 2. Бронювання та розрахунок вартості

\* Перевірка вільності залу на обраний інтервал (щоб уникнути накладання бронювань).

\* \*\*Гнучке ціноутворення\*\*:

&#x20; \* 🌅 \*\*Ранкові години (06:00 – 09:00)\*\* — знижка \*\*10%\*\*.

&#x20; \* ☀️ \*\*Стандартні години (09:00 – 18:00)\*\* — базова вартість.

&#x20; \* ⚡ \*\*Пікові години (12:00 – 14:00)\*\* — націнка \*\*15%\*\*.

&#x20; \* 🌙 \*\*Вечірні години (18:00 – 23:00)\*\* — знижка \*\*20%\*\*.

\* Додавання фіксованої вартості обраних додаткових послуг.
